GST Calculator

A modern and responsive GST Calculator built using React, Vite, and Tailwind CSS. It helps users calculate GST for both GST Exclusive (Add GST) and GST Inclusive (Remove GST) amounts with a detailed tax breakdown.

Live Demo

🔗 https://gst-calculator-xi.vercel.app/

GitHub Repository

https://github.com/tejasreemomula/gst-calculator

Features
Calculate GST Exclusive (Add GST)
Calculate GST Inclusive (Remove GST)
Supports GST rates: 0%, 5%, 12%, 18%, and 28%
Displays Original Amount
Displays GST Amount
Displays Total Amount
CGST and SGST breakdown
Copy Result functionality
Responsive design for desktop and mobile
Modern dark-themed UI
Fast calculations with instant updates
